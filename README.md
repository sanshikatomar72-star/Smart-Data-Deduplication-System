# Smart Data Deduplication and Storage Optimization System

## About the Project
Smart Data Deduplication and Storage Optimization System is a Python-based desktop application that identifies duplicate files and helps reduce unnecessary storage usage using SHA-256 hashing.

## Features
- File Scanning
- Duplicate File Detection
- SHA-256 Hashing
- Storage Analysis
- File Type Analysis
- Duplicate Priority Analysis
- Quarantine Management
- PDF and CSV Report Generation
- RAM Monitoring

## Technologies Used
- Python
- Tkinter
- SQLite
- SHA-256
- Matplotlib
- psutil

## Project Objectives
- Identify duplicate files.
- Analyze storage utilization.
- Reduce unnecessary storage usage.
- Generate reports of duplicate files.
- Improve file management.

## Project Status
Developed as an academic minor project.
